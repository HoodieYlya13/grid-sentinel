Grid Control Plane & Simulation Overview

This console monitors a live, self-healing grid cluster. NASA Space Weather API data dynamically sets workload stress (scaling CPU, Jobs, and Network). To demonstrate remediation, a latent memory leak is scheduler-injected on grid-worker-02. An unsupervised Isolation Forest ML model trains on healthy history, using locked-baseline gating to filter out normal workload fluctuations. It detects the progressive memory leak early (at ~50%-60% RAM, well before the 90% static fail-safe threshold) and triggers an Ansible recovery playbook to restore container health.

01

Puppet ENC Configuration

Worker nodes bootstrap and check-in to fetch dynamically compiled configuration states via ENC webhooks.

02

ML Outlier Detection

An unsupervised Isolation Forest algorithm fits dynamically on healthy telemetry history to identify leaks.

03

Ansible Recovery loop

Upon detection of anomalies, automated workflows gracefully drain container tasks and execute reboot playbooks.
